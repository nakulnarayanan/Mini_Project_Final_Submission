# Mini_Project_Final_Submission
Mini_Project_Final_Submission
This is a mini project I had done as part of the AI Driven Data Analytics Course. This includes the analysis of a healthcare dataset which includes patient and hospital details for 1000 patients with different medical conditions.

I had cleaned the data using excel and created the interactive dashboard using PowerBI visualization techniques.
Created  few calculated columns like number of days admitted, Age group etc.
Calculated few measures to identify the different values.
Created 2 different dashboards for Medical condition analysis and Insurance and billing amount analysis.
Also added Slicers and bookmarks to make the dashboard interactive.
Used different types of charts like line chart, bar chart, column chart, pie chart, donut chart, scatter plot chart etc.
Also customized the visuals using format visual options.
Added 2 buttons for navigation.
Created a new table for showing the hospitals with most number of admissions.
Created a matrix visual for showing Medications given to number of peoples.
